# SeekUni - University Finder Platform 🎓

**SeekUni** is an AI-powered platform designed to help students find their perfect university match in Turkey. It provides personalized recommendations, detailed university data, and an interactive chat assistant.

## 🚀 Features
*   **AI Chat Assistant**: Ask questions about universities and departments using natural language (powered by OpenAI).
*   **Smart Filtering**: Filter universities by faculty, department, and location.
*   **Comprehensive Data**: Detailed info on tuition, scholarships, and admission criteria.
*   **Responsive Design**: Modern, clean UI built with HTML/CSS and Streamlit.

## 🛠️ Tech Stack
*   **Frontend**: HTML5, CSS3, JavaScript
*   **Backend / AI**: Python (Streamlit), OpenAI API
*   **Data**: Pandas (CSV processing)

## 📦 Setup & Run
1.  **Install Dependencies**:
    ```bash
    pip install streamlit pandas openai
    ```
2.  **Configure API Key**:
    *   Open `website D1/universities.py`.
    *   Add your OpenAI API Key.
3.  **Run the App**:
    ```bash
    streamlit run "website D1/universities.py"
    ```
